# Phosphoproteomics Analysis

## Overview

Hands-on training project focused on phosphosite-level proteomics analysis.

## Workflow

Phosphosite data
→ QC
→ Differential phosphorylation
→ Localization confidence
→ FDR correction
→ Volcano plot
→ Pathway interpretation

## Tools

- Python
- Pandas
- SciPy
- Matplotlib

## Key concepts

- Phosphoproteomics
- PTMs
- Phosphosites
- Serine / Threonine / Tyrosine
- Site localization
- Differential phosphorylation
- FDR
- Pathway interpretation

## Dataset

This repository uses a simulated training dataset created for learning
phosphoproteomics analysis. It is not clinical or proprietary data.
